🎓## Online Learning Platform Analysis

##📌 Project Overview

This project analyzes an online learning platform to identify the factors influencing student course completion rates, learning engagement, and overall learning outcomes. Using Python, SQL, and Power BI, the analysis explores enrollment patterns, quiz performance, and course completion trends to generate actionable business insights and recommendations.

##🎯 Problem Statement

What factors influence students' course completion rates, and how can the platform improve student engagement and learning outcomes?

## Project Objectives

Analyze student enrollment patterns across different course categories.

Evaluate the relationship between quiz performance and course completion.

Identify course categories and levels with the highest and lowest completion rates.

Generate data-driven recommendations to improve student engagement and course completion.

##🛠️ Tools & Technologies

Python: Data cleaning, preprocessing, and exploratory data analysis.

SQL: Data extraction, transformation, joining, and analysis.

Power BI: Data modeling, DAX calculations, and interactive dashboard development.

Microsoft Excel: Supporting data validation and inspection.

##🔍 Analysis Process
Data from ngulikdata.com

Data Preparation: Cleaned and prepared the dataset using Python.

Data Exploration: Used SQL to explore relationships, identify patterns, and analyze key metrics.

Data Modeling: Built relationships between datasets to support analytical requirements.

Data Transformation: Created a course completion status based on completion dates, classifying students as Completed or In Progress.

Data Visualization: Developed an interactive Power BI dashboard to communicate key findings.

##📊 Dashboard Key Features

Enrollment KPIs: Displays total enrollments and overall course completion rate.

Enrollment by Course Category: Compares enrollment distribution across course categories.

Quiz Performance: Compares average quiz scores between students who completed courses and those still in progress.

Completion Status by Quiz Result: Analyzes course completion status based on quiz outcomes (Passed and Failed).

Completion Rate by Course Category: Identifies categories with higher and lower completion rates.

Completion Rate by Course Level: Compares completion rates across Beginner, Intermediate, and Advanced courses.

##💡 Key Business Insights

Quiz Performance: 69.24% of students who failed the quiz remained in progress, while 51.20% of students who passed successfully completed their courses.

Course Level: Advanced courses recorded the highest completion rate, while Intermediate courses had the lowest.

Course Popularity: Python and SQL were among the most enrolled course categories.

##🚀 Business Recommendations

Improve Quiz Feedback: Provide detailed explanations for incorrect answers and additional learning resources to help students understand difficult topics.

Enhance Student Engagement: Introduce interactive learning activities and progress reminders to encourage students to continue their courses.

Optimize Intermediate Courses: Review course structure, learning materials, and difficulty levels to address the lower completion rate.

Collect Student Feedback: Implement regular course evaluations to identify learning difficulties and improve the overall learning experience.

##📈 Expected Business Impact

The analysis provides insights into student learning behavior and course performance, helping the platform identify potential barriers to course completion. These findings can support data-driven decisions to improve learning experiences, strengthen student engagement, and increase course completion rates.
